KyberBridge is a one click exe for hosting a dedicated server through Kyber for Star Wars Battlefront 2 2017.

Features:
- Set launch args via JSON incl: Map, Mode, Mods.
- Upon completion of game, a BattleResult JSON will be generated. This can be used to determine the winner and loser, useful for stats or custom apps.
